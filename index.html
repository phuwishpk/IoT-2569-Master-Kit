⭐ วงจรที่ 7: Standard IoT Station (POT 10k + LED)

ใช้ซ้ำได้ถึง 4 สัปดาห์ (Week 02, 10, 11, 12)

ต่อครั้งเดียวบน Breadboard ปล่อยไว้เลย ไม่ต้องรื้อวงจรใหม่!

• ขา 3V3 (ซ้ายแถว 1): สายสีแดง → ขา 1 ของ POT
• ขา G2 (ขวาแถว 14): สายสีส้ม → R 220Ω → Anode (+) LED
• ขา G34 (ซ้ายแถว 5): สายสีน้ำเงิน → ขากลาง Wiper ของ POT
• ขา GND (ขวาแถว 1): สายสีดำ → Cathode (-) LED
• ขา GND (ซ้ายแถว 14): สายสีดำ → ขา 3 ของ POT

🟣 วงจรที่ 6: จอแสดงผลกราฟิก SPI OLED SSD1306 (7 ขา) + POT

Week 09: SPI OLED & Kestrel UI
• Pin 1 (GND): สายสีดำ → ขาขวาแถว 1 (GND)
• Pin 5 (RES): สายสีฟ้า → ขาขวาแถว 13 (GPIO 4)
• Pin 2 (VCC): สายสีแดง → ขาซ้ายแถว 1 (3.3V ห้ามต่อ 5V)
• Pin 6 (DC): สายสีชมพู → ขาขวาแถว 14 (GPIO 2)
• Pin 3 (D0/SCK): สายสีเหลือง → ขาขวาแถว 9 (GPIO 18)
• Pin 7 (CS): สายสีส้ม → ขาขวาแถว 12 (GPIO 5)
• Pin 4 (D1/MOSI): สายสีเขียว → ขาขวาแถว 6 (GPIO 23)

🟢 วงจรที่ 4: เซนเซอร์วัดแสง LDR + ตัวต้านทานแบ่งแรงดัน R 10k

Week 03: LDR Calibration
• ขา 3V3 (ซ้ายแถว 1): สายสีแดง → ขา 1 ของ LDR
• ขา 2 ของ LDR: ต่อเข้าจุดแยก (Divider Node)
• จุดแยก (Divider Node): สายสีน้ำเงิน → ขา G34 (ซ้ายแถว 5)
• จุดแยก (Divider Node): ต่อผ่านตัวต้านทาน R 10k ลง GND
• ขา GND (ซ้ายแถว 14): สายสีดำ → ขา R 10k อีกข้าง

🔴 วงจรที่ 5: หลอดแม่สี RGB LED (Common Cathode) + LDR

Week 04: RGB Color Sensing
• ขา Red Anode (+): สายสีแดง → R 220Ω → ขา G4 (ขวาแถว 13)
• ขา Green Anode (+): สายสีเขียว → R 220Ω → ขา G5 (ขวาแถว 12)
• ขา Blue Anode (+): สายสีน้ำเงิน → R 220Ω → ขา G23 (ขวาแถว 6)
• ขายาว Common Cathode (-): สายสีดำ → ขา GND (ขวาแถว 1)
• เซนเซอร์ LDR: วางคู่ขนาน หันหน้ารับแสงสะท้อนจากวัตถุ เข้า G34

🛠️ เครื่องมือช่วยเหลือตรวจพอร์ต COM & เชื่อมต่อผ่าน SSH

1. สคริปต์ตรวจพอร์ต ESP32 และเครือข่ายอัตโนมัติ (remote_doctor.py)

ใช้เมื่อเสียบบอร์ดแล้วหาพอร์ต COM ไม่เจอ หรือพอร์ตถูกโปรแกรมอื่นจองค้างอยู่:

python remote_doctor.py --clear-port
2. รีโมตเข้าเครื่องเพื่อนผ่าน SSH ข้ามวงแลน (ssh_deploy.sh)

ใช้ส่งโค้ดหรือล็อกอินเข้าเครื่องเพื่อนเพื่อรันคำสั่งพร้อมกัน:

chmod +x ssh_deploy.sh
./ssh_deploy.sh -u <USERNAME> -h <IP_ADDRESS>
